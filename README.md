# Patttttern

Generates pattern SVG and PDF files.

## Setup

Install dependencies:

```bash
pip install svgwrite
```

## Run Guide

Always run from the project root and use module paths with python -m.

```bash
python -m close_fitting_bodice.main
python -m close_fitting_bodice.one_dart_front
python -m close_fitting_bodice.base.front
python -m close_fitting_bodice.base.back
python -m close_fitting_bodice.a4
```
