# Patttttern

Generates pattern SVG and PDF files.

## Setup

Install dependencies:

```bash
pip install svgwrite
```

## Run Guide

Always run from the project root and use module paths with python -m.

```bash
python -m aldrich_close_fitting_bodice.main
```

Run all pattern generators from the repository root:

```bash
python run_all.py
```

## Scale for Autodesk Fusion 360

After importing the generated svg, scale by `3.77957517575`.
